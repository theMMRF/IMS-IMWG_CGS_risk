# IMS-IMWG Consensus Genomic Staging (CGS)

According to the IMS-IMWG's [Consensus Genomic Staging (CGS) of high-risk multiple myeloma (HRMM)](https://ascopubs.org/doi/10.1200/JCO-24-01893), "high risk" is defined as meeting one or more of the following criteria:

1. del(17p), with a cutoff of >20% clonal fraction, and/or TP53 mutation
2. an IgH translocation including t(4;14), t(14;16), or t(14;20) with 1q+, and/or del(1p32)
3. monoallelic del(1p32) with 1q+, or biallelic del(1p32)
4. β2 microglobulin ≥5.5 mg/L with normal creatinine (<1.2 mg/dL)

If any criteria is true, then label as "High Risk".
If all criteria are false, label "Standard Risk".
Otherwise, label NA.
